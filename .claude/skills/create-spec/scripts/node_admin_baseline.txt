# Node-admin RPCs already served from a base collection on `main`.
#
# A row here is a DEBT RECORD, not an exemption: it says "known, ticketed, not a
# regression introduced by this PR". Fixing the spec is what removes the row.
# Adding a row for a NEW exposure defeats the guard — resolve it instead
# (disable, or gate behind an add_on). See check_node_admin_rpcs.sh.
#
# Format: <spec-file> <INDEX> <interface> <method> [TEMPORARY]
#
# A row whose method is no longer exposed is STALE and FAILS the guard — delete
# it. That is deliberate: a stale row would silently re-permit the method if the
# fix were ever reverted, so the ledger cleans itself. The `TEMPORARY` token is
# the one exception, for a fix already in flight on another branch: a stale
# TEMPORARY row is reported loudly but does not fail, so the merge that makes it
# stale does not turn someone else's CI red.
#
# Established by sweeping the catalogue at the time the guard was written
# (MAG-3644 item 4). Everything else the sweep found — `debug_setHead` on
# codex / etc / flare / ink / race / xdc — sits behind the `debug` add-on and is
# therefore out of scope by design, not baselined.

# priced relays with no opt-in boundary — a worse class than the stalled tip
# MAG-3644 was opened for. Tracked separately: MAG-3808.

# upstreams answer -32601, so probes will look clean. Per the free-tier rule
